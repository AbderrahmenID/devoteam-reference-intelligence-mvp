# Reference pack editable template

Template `DEVOTEAM_REFERENCE_PACK_V1` is defined centrally in
`templates/reference_pack/v1/template_config.yaml`.

- Canvas: 13.333 × 7.5 inches, 16:9.
- Source PDF SHA-256:
  `bc01334088c95c3796f1b98586e4980c66fd084c45174eec23ff03195bb39334`.
- Accent: Devoteam coral `#F8475E` sampled from editable source elements.
- Background/headings: white and near-black with compact coral underlines.
- Latin/Arabic fonts: Verdana/Arial.
- Footer: approved local Devoteam asset plus visible slide number.
- Summary density: up to three references and six source bullets per slide.
- Details: one selected reference per slide.
- Evidence: up to two cards per slide, never below 10 pt.

Implemented editable layouts are cover, page-10-inspired section divider,
pages-11–17-inspired horizontal summary cards, detailed reference panels, and
pages-18–29-inspired evidence-card annexes. No source PDF page is a slide
background.

The client-logo registry is empty by design. Without an reviewed local logo,
the generator uses a client-name card. The existing Devoteam footer asset was
cropped from authorized source page 10 and is not redrawn. See
`REFERENCE_PACK_TEMPLATE_ANALYSIS.md` for the page-by-page findings.
