## Relevant source modules

- `phase3_extraction.py`, `phase3_quality.py`, `phase3_security.py`: digital PDF extraction, `fra+eng+ara` OCR fallback, provenance and quality handling.
- `phase3_1_repair.py`: bounded offline OCR repair; intentionally not migrated wholesale.
- `phase4_corpus.py`: conservative normalization, approximate language detection and page-constrained chunking.
- `phase5_bm25.py`: reusable pickle-free Unicode BM25 representation and tokenizer.
- `phase5_retrieval.py`: pinned E5 prefixes, normalized local embeddings, hard filters and weighted RRF.
- `phase5_2_matching.py`: useful query validation, term coverage, deterministic filtering and citation integrity patterns; broader opportunity matching is out of MVP scope.

## Reusable tests

Behavior was retained from source tests covering multilingual normalization, exact-term ranking, pickle-free BM25 round trips, hard authorization masks, deterministic hybrid fusion, citation preservation, normalized dense vectors, digital-PDF OCR avoidance and Arabic-preserving extraction normalization. The MVP has focused tests under its own `tests/` directory rather than copying historical test suites.

## Risks

- Tesseract and its French/English/Arabic language packs are not locally installed; only the offline OCR fallback is blocked.
- Human multilingual qrels do not exist, so no official relevance metric can be claimed.
- Dense runtime requires the pinned local model plus compatible `sentence-transformers`; startup must not download models.
- Corpus metadata is predominantly French and may contain source-level inconsistencies; evidence remains unchanged.
