# DEVOTEAM_REFERENCE_PACK_V1

Version `1.0.0` recreates the reference-pack visual language from the authorized
PDF without using PDF pages as slide backgrounds. Every heading, card, rule,
footer, citation and slide number is created as an editable PowerPoint element.

The measured 16:9 geometry, colors, typography, spacing, card layouts and
pagination constants live only in `template_config.yaml`. The Devoteam logo in
`assets/devoteam_logo.png` is an unmodified crop of the existing brand asset on
source page 10. The source PDF is preserved byte-for-byte under
`templates/reference_pack/source/`.

No client logo is approved in `logo_registry.yaml`. Until an authorized local
asset is registered, presentations show a client-name card. Do not download,
redraw or infer client logos.
